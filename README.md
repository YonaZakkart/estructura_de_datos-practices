# Prácticas de Estructura de Datos

Repositorio destinado a la resolución de prácticas de laboratorio y proyectos aplicados de Estructura de Datos.

## Estructura del Repositorio

El proyecto está organizado por prácticas independientes:

```text
estructura_de_datos-practices/
├── practice01/         
├── practice02/
├── ...
├── .gitignore
└── README.md
```
Nota: Cada carpeta de práctica cuenta con su propio README.md detallando los objetivos específicos y la forma de ejecución individual.

## Tecnologías y Dependencias
Lenguaje base: Python 3.x

## Configuración del Entorno
Clonar el repositorio:

- HTTPS
```Bash
git clone https://github.com/YonaZakkart/estructura_de_datos-practices.git
```
- SSH
```Bash
git clone git@github.com:YonaZakkart/estructura_de_datos-practices.git
```
```bash
cd estructura_de_datos-practices
```

## Ejecución
Para probar una práctica en específico, dirígete a su carpeta y ejecuta los archivos .py disponibles:

```Bash
cd Practica01
```
```bash
python actividad.py
```
